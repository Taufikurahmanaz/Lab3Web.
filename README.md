# Lab3Web.
LAPORAN PRAKTIKUM PEMROGRAMAN WEB
Materi: CSS Dasar (Internal, External, & Inline CSS)

Mata Kuliah: Pemrograman Web

1. PENDAHULUAN
Praktikum ini bertujuan untuk mempelajari dan memahami dasar-dasar penggunaan Cascading Style Sheets (CSS) dalam mendesain halaman web. Praktikum mencakup penerapan tiga jenis metode penulisan CSS, yaitu Internal CSS, Inline CSS, dan External CSS, serta penggunaan selector tingkat lanjut seperti ID Selector dan Class Selector.

3. KESIMPULAN
Dari praktikum yang telah dilakukan, dapat disimpulkan bahwa:

CSS sangat berperan penting dalam memperindah dan mengatur tata letak (layout) halaman web yang sebelumnya hanya berupa struktur teks biasa dengan HTML.

Terdapat tiga cara penulisan CSS yaitu Internal CSS (dalam satu file HTML pada tag <style>), Inline CSS (langsung pada tag elemen tertentu), dan External CSS (menggunakan file terpisah berekstensi .css), di mana penggunaan CSS eksternal merupakan cara yang paling disarankan untuk merawat kode agar lebih rapi dan terstruktur.

Penggunaan ID Selector dan Class Selector mempermudah dalam memberikan styling yang spesifik pada elemen-elemen tertentu di dalam halaman web.
